# 《他的手机》第四章 · 还在生气吗？（执行剧本 V1.2）

## 章节原则
- 第三章已经解除拉黑，但并未和好；第四章只呈现别扭中的互相关心。
- 不解释“你又这样”的含义。后续济州岛与海底捞事件才回收伏笔。
- 不重复第二章 IG 私信出现的黑色外套。
- 聊天像真实手机消息：简短、可撤回、可有沉默和无关紧要的生活话题。
- 日历（含待办）与外卖民族 Baemin 是可选探索，前三章保持锁定；不参与任何主线通关条件。
- 备忘录提示新功能开放，并在群聊后提示私聊询问咖啡。
- 两次关键追问（“又这样”、撤回）必须由玩家选择；允许暂时退出，返回后继续。
- 玩家可回看历史聊天；没有重新开始阅读按钮。
- 本章虚构私聊与公开事件应清晰区分。

## 01 恢复联系
条件：第三章完成，进入第四章。备忘录出现「已解锁：日历（含待办）和外卖民族。可以随时去看看」。

随后群聊更新。

## 04 撤回与蒸面包

玩家必须选择：刚发什么了 / 干嘛撤回ㅋㅋ / 我看见你撤回了

宋亨俊发送蒸面包照片（需绑定用户已有图片），说：你之前叫我买的这个 / 刚刚看到了

## 05 深夜电话
宋亨俊主动来电。允许接听；拒接后再次来电，避免错过主线。
通话：喂 → 怎么还没睡 → 你怎么知道我没睡ㅋㅋ → 刚刚不是还在回消息吗 → 啊ㅋㅋ → 今天头还疼吗 → 好多了 → 真的？ → 嗯真的 → 那就好 → 早点睡吧 → 你也是 → 嗯。
头疼承接第三章中「偶尔还有点头疼」的既有设定。
电话完成后记录通话、完成第四章，聊天及探索内容仍可查看。
